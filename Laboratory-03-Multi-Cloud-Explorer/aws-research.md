# Amazon Web Services (AWS) Research Documentation

## Brief Overview
Launched in 2006 by Amazon, AWS is the pioneer and undisputed market leader in cloud computing. It provides a massive, reliable, and secure global cloud platform that powers millions of enterprises worldwide.

## Global Infrastructure
* **Regions:** 33+ geographic regions globally.
* **Availability Zones (AZs):** 105+ isolated locations with independent power, cooling, and networking.
* **Edge Locations:** Hundreds of Points of Presence (PoPs) worldwide for low-latency content delivery via Amazon CloudFront.

## Cloud Management Console
* **Web Portal:** AWS Management Console (unified browser dashboard).
* **Command Line Tools:** AWS CLI, AWS CloudFormation, and AWS SDKs.

## Four (4) Core Services
1. **Compute:** Amazon EC2 (Elastic Compute Cloud) for scalable virtual servers.
2. **Storage:** Amazon S3 (Simple Storage Service) for durable object storage.
3. **Database:** Amazon RDS (Relational Database Service) for managed SQL databases.
4. **Networking:** Amazon VPC (Virtual Private Cloud) for isolated cloud network resources.

## Three (3) Advantages
1. **Extensive Service Maturity:** Offers the broadest catalog of advanced services (AI, IoT, Quantum Computing).
2. **Massive Ecosystem & Community:** Unmatched documentation, community tutorials, and third-party integrations.
3. **Enterprise Security and Compliance:** Built-in compliance standards meeting rigorous global defense and finance requirements.

## Typical Enterprise Use Cases
* Scalable multi-tier web applications and global e-commerce systems.
* Big data analytics processing and data warehousing (e.g., Amazon Redshift).
* Enterprise disaster recovery and backup archiving.
