## 2. Evaluation Questions

1. **Which cloud provider offers the broadest range of services?**
   Amazon Web Services (AWS) offers the broadest and most mature range of services. Having launched years ahead of its competitors, AWS features an extensive catalogue spanning foundational infrastructure all the way to advanced quantum computing and specialized edge solutions.

2. **Which provider best integrates with Microsoft technologies?**
   Microsoft Azure provides the best native integration with Microsoft technologies. Because Azure shares a software lineage with Windows Server and Active Directory (now Entra ID), it offers seamless hybrid management, license mobility, and support for enterprise .NET applications.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   Google Cloud Platform (GCP) leads in Artificial Intelligence and Kubernetes infrastructure. Google originally created Kubernetes (yielding GKE as the gold standard for container orchestration) and powers cutting-edge AI via Vertex AI and custom TPUs.

4. **Which cloud platform would you personally choose and why?**
   *(Example Response)* I would personally choose Google Cloud Platform (GCP) for modern fullstack and data-driven projects. Its straightforward console design, superior data tools like BigQuery, and exceptional container workflows via GKE align seamlessly with modern web development paradigms.
