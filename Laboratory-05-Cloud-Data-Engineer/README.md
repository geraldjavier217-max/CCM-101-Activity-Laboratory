# Laboratory 05 – The Cloud Data Engineer

## Mission Overview

This laboratory focused on cloud object storage using MinIO. The task involved deploying an S3-compatible object storage server using Docker, accessing its web console, creating a storage bucket, and uploading a test object.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through port forwarding.
- Create an object storage bucket.
- Upload an object to the bucket.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

- Understanding different cloud storage types
- Deploying containerized cloud services
- Using Docker environment variables
- Working with MinIO object storage
- Creating and managing storage buckets
- Uploading objects to cloud storage
- Documenting technical procedures using Markdown
