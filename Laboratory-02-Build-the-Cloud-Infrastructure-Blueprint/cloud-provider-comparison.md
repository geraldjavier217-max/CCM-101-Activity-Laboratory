1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is generally considered the cloud provider with the broadest range of services. It offers hundreds of cloud services covering computing, storage, networking, analytics, machine learning, security, and application development.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure. It integrates seamlessly with Microsoft technologies such as Windows Server, Active Directory, Microsoft 365, and SQL Server, making management easier for organizations already using Microsoft products.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for AI, ML, and Kubernetes services. Google developed Kubernetes and provides advanced AI tools such as Vertex AI and TensorFlow-based solutions.

4. What similarities did you observe among the three cloud providers?

All three providers offer core cloud infrastructure services including compute, storage, networking, and identity management. They also provide scalable, secure, and on-demand resources that support modern cloud applications and enterprise workloads.
