
Mission Reflection

Among all cloud infrastructure components, I believe compute resources are the most important because they provide the processing power required to run applications, services, and workloads. Without compute resources such as CPUs and memory, cloud systems would not be able to process data or deliver services to users. While storage and networking are also essential, they depend on compute resources to function effectively.

Linux plays a major role in cloud computing because it is stable, secure, and highly efficient. Most cloud providers use Linux-based systems to host servers, containers, and virtual machines. Linux also offers powerful command-line tools that allow administrators and cloud engineers to manage infrastructure efficiently. Its open-source nature makes it flexible and cost-effective for organizations of all sizes.

Technical documentation is important before deploying infrastructure because it helps engineers understand the system design, requirements, and implementation plan. Proper documentation reduces errors, improves communication among team members, and provides a reference for troubleshooting and future upgrades. It also ensures that infrastructure decisions are clearly justified and recorded.

During this laboratory activity, I learned how to investigate a Linux server and identify important cloud infrastructure components such as compute, storage, networking, and operating systems. I also learned how different cloud providers offer similar services under different names and how these services work together to support cloud environments. Additionally, I improved my skills in using Markdown for technical documentation.

My GitHub portfolio improved significantly after completing this mission because it now contains more organized documentation and evidence of practical cloud computing activities. The repository demonstrates my ability to analyze cloud infrastructure, document findings professionally, and apply cloud computing concepts in a real-world environment. This experience has strengthened both my technical and documentation skills.
